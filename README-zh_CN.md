# 大学生生涯模拟器 · DEVLIFE

基于 VickScarlet/remake（MIT）的文字生涯模拟游戏。选择专业和天赋，从大学报到走到毕业后的第一年。网页首页也提供「程序员职场篇」。

## 启动网页

需要 Node.js 22.12+（建议 24）及 pnpm。首次在项目根目录执行：

```sh
pnpm install --frozen-lockfile
pnpm dev
```

打开 http://127.0.0.1:5173 。内容直接来自 TypeScript，不需要运行 Excel 转换。

```sh
pnpm build:web   # 生成 apps/web/dist，可部署到静态站点
pnpm preview    # 预览生产构建
pnpm typecheck  # 网页和共享依赖类型检查
pnpm build:data # 内容类型检查，无生成步骤
```

规则测试及终端客户端另外需要 Bun（已用 1.4.2 验证）：

```sh
pnpm test        # 规则、内容完整性、存档测试
pnpm dev:console # 终端版
pnpm build:console
```

## 大学生篇

选择一个专业，抽取三项天赋并分配四项初值。四年大学和毕业后第一年共 20 个季度，完整一局有 9 次关键选择。

| 专业 | 专属经历与部分去向 |
| --- | --- |
| 计算机科学与技术 | 校园工具、实验复现、软件工程与工程研究 |
| 机械设计制造及其自动化 | 制图与装配、制造工艺、结构设计与质量检测 |
| 会计学 | 费用核算、经营预算、凭据核验与审计 |
| 汉语言文学 | 文本细读、课堂试讲、稿件编辑与社区阅读 |
| 视觉传达设计 | 导视测试、作品交付、公共信息与品牌视觉 |
| 护理学 | 模拟实训、带教交接、病区与社区服务 |

- 大学生活包含同伴互助、勤工助学、预算和时间取舍。日常经历与选择会影响专业能力、沟通、健康、积蓄和心态。
- 专业实践与毕业作品分别积累申请经历。也可以实践选一个方向，毕设再尝试另一个方向。进度卡可以展开查看已经解锁的专项去向。
- 每个专业有三个毕业去向，并有相应的毕业后事件。健康或心态耗尽时，人生进度条保留实际走过的季度，进入休整结局。
- 结算页展示去向依据、五维雷达、选择引起的直接变化及事件结果。点「保存档案，返回首页」后，专业选择页会显示已探索的去向数。

## 程序员职场篇

- 自由创建：抽取 10 个天赋，选择 3 个；基础 20 点分配到沟通、技术、健康、积蓄，单项上限 10。部分天赋增加可分配点数。
- 职业出身：从科班应届生、自学转行者等 6 种背景中选择；查看配置后直接入职。
- 心态初始为 5，天赋在入职日或指定季度触发。入职日为第 0 回合，之后为 36 个季度，共九年。
- 点击“下一季度”逐步阅读，或开启自动运行。第 1、3、6、10、12、18、21、24、30、33 季度包含关键对话，自动运行会暂停等待玩家选择，并在选择后继续。
- 健康或心态耗尽时提前退出高压工作、进入休整结局；其余职业在第 36 季度复盘。
- 9 类结局：技术专家、团队领航员、自由开发者、生活架构师、可靠的工程师、可靠性工程师、数据产品负责人、无障碍体验工程师，以及休整重启。
- 总结显示结束时属性；成长分沿用峰值累计公式，作为游戏记录。积蓄是抽象点数，不代表真实工资或现金。
- 复盘后可保留一项天赋；点击“保存档案，返回首页”完成跨局存档。档案保存在当前浏览器，使用独立的 `devlife:v1:` 命名空间。进行中的一局不支持刷新续玩。

对话中可选择代码评审、学习与休息、事故处理、跳槽、技术或管理路线、开源投入和独立开发。选项显示属性代价，能力不足的选项会显示解锁条件；支持鼠标、键盘焦点和数字键选择。选择会解锁后续事件、影响职业结局，并在复盘中展示。日常事件仍按能力与经历自动判定。

当前采用关键节点决策，尚未加入工资结算或公司经营。

## 课程数据库设计

PostgreSQL 存储内容快照、跨局档案与已完成的生涯。校园版新增按专业区分的季度池，和原职场篇共用档案。升级时执行 `pnpm setup:local` 同步内容，再执行 `pnpm start:local`。详见 [运行说明](packages/database/README.md)。此前职场篇的课程报告见 [ER 图与数据字典](docs/database/index.html) 及 `output/pdf/`。

## 修改内容

- `packages/data/src/campus/`：大学生篇的专业、实践、毕设、岗位与结果事件。
- `packages/data/src/programmer/`：共享天赋与成就，以及原程序员职场篇的职业出身和剧情。
- `packages/data/etc/display.ts`：属性名称、季度展示、评级文案。
- `apps/web/src/components/Workspace.*`：代码工作区外观与响应式布局。
- `apps/web/src/components/Dialogue.*`：角色对话、选择、条件提示与即时影响。
- `packages/data/src/programmer/decisions.ts`：10 个关键决策点与后续结果。
- `packages/core/`：共享游戏引擎；修复天赋次数上限、抽卡不足和背景池耗尽问题。
- `packages/vitex/`：修复小数权重抽取，并保留 RNG 注入协议。

原版 Excel 文件保留作上游参考，已不进入运行时。新增内容请修改 TypeScript 源文件。

### DeepSeek 深度复盘

本地 API 服务读取环境变量 `DEEPSEEK_API_KEY`，也支持在项目的 `.local/deepseek.env` 中设置同名变量。该文件已被 Git 忽略，更新后需要重启 API。默认模型为 `deepseek-flash`，可用 `DEEPSEEK_MODEL` 覆盖。开发时 Vite 会将 `/api/review` 转发到本机 8787 端口。在结算页点击「生成深度复盘」时才发送本局路线、事件、决定及五维属性。提示词位于 `packages/database/lib/review.mjs`。模型不可用时仍可查看本地的取舍分析。

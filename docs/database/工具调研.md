# 数据库选型与工具复用（2026-11-10）

推荐 PostgreSQL，已实际配置并运行原生 PostgreSQL 18.6。判断依据是现有复杂事件关系、跨局档案、并发版本控制及 JSON 快照需求，属于本项目适配意见。

| 候选 | 判断 |
| --- | --- |
| PostgreSQL | 外键、事务、行锁与 JSONB 可结合；延续现有 SQL 和 Knex，适合完整软件。 |
| MySQL 8.4 | 原生 JSON 可实现同类需求，但当前 PostgreSQL SQL 与触发器需改写，本次无切换收益。 |
| SQLite | 单机离线版可考虑；当前后端与并发写入演示选择客户端/服务器数据库更合适。 |

主资料：[PostgreSQL JSONB](https://www.postgresql.org/docs/18/datatype-json.html)、[PostgreSQL 行锁](https://www.postgresql.org/docs/18/explicit-locking.html)、[MySQL JSON](https://dev.mysql.com/doc/refman/8.4/en/json.html)、[SQLite 适用场景](https://www.sqlite.org/whentouse.html)。

工具：Knex 3.3.0 管理迁移与种子；pg 8.23.1 连接实际实例；tbls 1.96.1 提取实际结构与检查注释及索引；Viz.js / Graphviz 重绘完整及分域矢量 ER 图。DrawDB 可作为后续人工调图工具，本轮没有上传项目数据。PDF 使用 ReportLab 生成并渲染检查。

Windows 原生二进制固定为 [embedded-postgres](https://github.com/leinelissen/embedded-postgres) 的 @embedded-postgres/windows-x64 18.6.0-beta.19。实际引擎为 PostgreSQL 18.6，包装版本 beta 不表示使用 PGlite 或内存模拟服务。下载包按 npm SHA-512 核验；本轮 EDB 下载端连接超时后，采用可核验的固定 npm 包。未运行来自未知来源的安装程序。
